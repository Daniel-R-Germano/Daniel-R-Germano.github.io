# Portfólio Vertical

Portfólio estático pronto para GitHub Pages, com rolagem vertical e fundo trocando de acordo com a seção ativa.

O conteúdo está orientado para apresentação de resumo pessoal, formação, habilidades técnicas, projetos, carreira profissional, currículo e contato.

## Editar conteúdo

- Troque `Seu Nome`, `SN`, email, GitHub e LinkedIn em `index.html`.
- Atualize resumo e formação na seção `#sobre`.
- Ajuste tecnologias e disciplinas na seção `#habilidades`.
- Substitua os textos dos projetos na seção `#projetos`.
- Atualize experiências e objetivos na seção `#carreira`.
- Coloque seu PDF em `assets/documents/curriculo.pdf` para ativar o botão de download.
- Se quiser trocar os fundos, coloque novas imagens em `assets/backgrounds/` e ajuste o atributo `data-bg` de cada seção.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub chamado `seu-usuario.github.io`.
2. Envie estes arquivos para a branch `main`.
3. Acesse `https://seu-usuario.github.io`.

Também funciona em qualquer repositório comum usando `Settings > Pages > Deploy from a branch`.
