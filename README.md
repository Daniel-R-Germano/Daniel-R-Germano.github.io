# Daniel Germano | Portfolio

Portfolio pessoal estatico publicado com GitHub Pages.

O site apresenta resumo profissional, habilidades tecnicas, experiencia, projetos aplicados e links de contato. O foco do conteudo esta em Python, automacao, analise de dados, backend, bancos de dados, sistemas embarcados, RAG e LLMs.

## Projetos em destaque

- Manutencao Inteligente com RAG + LLM: sistema para manutencao de maquinas com dashboards de KPIs, controle de falhas, acompanhamento de troubleshooting, banco de dados, Python, Flutter Web e assistente de IA baseado em historicos de falhas e manuais de equipamentos.
- Planilha Excel com API da Copa 2026: planilha integrada a API para acompanhar jogos, resultados, palpites e pontuacao.

## Tecnologias

- HTML
- CSS
- JavaScript
- Python
- SQL
- RAG e LLMs
- Flutter Web
- Power Platform

## Estrutura

- `index.html`: estrutura e conteudo do portfolio.
- `styles.css`: estilos, responsividade e animacoes.
- `script.js`: menu ativo, rolagem suave, animacoes de entrada e texto digitando.
- `assets/documents/`: pasta para documentos, como curriculo em PDF.

## Publicacao

O portfolio esta configurado para GitHub Pages pelo repositorio:

```text
Daniel-R-Germano.github.io
```

Link publicado:

```text
https://daniel-r-germano.github.io/
```

Para publicar alteracoes:

```powershell
git add .
git commit -m "Atualiza portfolio"
git push
```

O GitHub Pages publica automaticamente a partir da branch `main`, usando a pasta `/ (root)`.
